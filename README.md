# Ev Kayıp Çorap Dedektifi 🧦

## Bu Nedir?

Bu, insanlık tarihinin en büyük gizemini çözen **bilimsel** bir projedir. Evinizde kaybolan çorapları bulur. Bulmaz. Ama rapor yazar. Çok ciddi raporlar.

**Başarı oranı:** %0.0001  
**Ciddiyet seviyesi:** %100  
**Mantık seviyesi:** %0

## Nasıl Çalışır?

1. Python 3 yüklü olsun.
2. `python corap_dedektifi.py` yaz.
3. Adını gir (veya girme, fark etmez).
4. Raporu oku. Çorabın nerede olduğunu öğren. (Ya da öğrenme.)

Kod gerçekten çalışır. Deneyin. Gülün. Sonra çoraplarınızı aramaya devam edin.

## Özellikler

- Rastgele absürt lokasyonlar üretir.
- Asla gerçek çorap bulmaz. (Bu bir özelliktir.)
- Gizli mesajlar içerir. (Sakladık, aramayın.)
- Mahkeme kararı gibi ciddi dil kullanır.

## Kurulum

```bash
git clone https://github.com/Tentivory/ev-kayip-corap-dedektifi.git
cd ev-kayip-corap-dedektifi
python corap_dedektifi.py
```

Başka bir şey gerekmez. Bağımlılık yok. Mantık yok.
